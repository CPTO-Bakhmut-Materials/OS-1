## Практична робота: Створення інтелектуального скрипта системного адміністрування

**Мета:** Розробити скрипт, який автоматично перевіряє стан системи (файли, користувачі, числа) за допомогою конструкцій `if-elif-else`.

---

### Етап 1: Перевірка існування об’єкта
**Завдання:** Скрипт має перевірити, чи існує файл конфігурації, шлях до якого ми передаємо.

**Покрокове розв’язання:**
1.  Створіть файл: `task.sh`.
2.  Додайте перевірку наявності аргументу (чи ввів користувач назву файлу).
3.  Використовуйте прапорець `-e` для перевірки існування.

```bash
#!/bin/bash

# Зберігаємо перший аргумент у змінну
FILE=$1

# Крок 1.1: Перевірка, чи не порожня змінна
if [ -z "$FILE" ]; then
    echo "Помилка: Ви не вказали шлях до файлу!"
    exit 1
fi

# Крок 1.2: Перевірка існування файлу
if [ -e "$FILE" ]; then
    echo "Об'єкт $FILE знайдено."
else
    echo "Об'єкт $FILE не існує."
fi
```

---

### Етап 2: Диференціація типів об’єктів
**Завдання:** Якщо об’єкт існує, скрипт має визначити: це звичайна директорія чи файл.

**Покрокове розв’язання:**
1.  Додайте вкладену умову всередину блоку, де файл було знайдено.
2.  Використовуйте `-d` (directory) та `-f` (file).

```bash
# Продовження логіки всередині умови [ -e "$FILE" ]
if [ -d "$FILE" ]; then
    echo "Це директорія (папка)."
elif [ -f "$FILE" ]; then
    echo "Це звичайний файл."
else
    echo "Це спеціальний тип об'єкта."
fi
```

---

### Етап 3: Числове порівняння (Логіка безпеки)
**Завдання:** Додайте перевірку "рівня доступу". Користувач має ввести числовий код. Якщо код менше 100 — доступ обмежений, рівно 777 — повний доступ (адмін), в інших випадках — стандартний доступ.

**Покрокове розв’язання:**
1.  Використовуйте команду `read` для отримання даних від користувача.
2.  Застосуйте оператори `-lt` (less than) та `-eq` (equal).

```bash
echo "Введіть ваш секретний код доступу:"
read CODE

if [ "$CODE" -eq 777 ]; then
    echo "ВІТАЮ, АДМІНІСТРАТОРЕ! Доступ до $FILE відкрито."
elif [ "$CODE" -lt 100 ]; then
    echo "Рівень доступу: ГІСТЬ. Ви можете лише переглядати $FILE."
else
    echo "Стандартний рівень доступу активовано."
fi
```

---

### Етап 4: Перевірка рядків (Пароль)
**Завдання:** Перед фінальним звітом скрипт має запитати кодове слово.

**Покрокове розв’язання:**
1.  Порівняйте введений рядок із константою за допомогою `==`.

```bash
echo "Введіть кодове слово (Password):"
read PASS

if [ "$PASS" == "Ferrum" ]; then
    echo "Перевірка успішна. Скрипт завершено."
else
    echo "Кодове слово невірне. Вихід..."
    exit 1
fi
```

---

**Як запустити:**
1. `chmod +x task.sh`
2. `./task.sh /etc/passwd` (або будь-який інший існуючий файл).
